# 移动端规范

面向 HarmonyOS / ArkTS 为主，规则对 React Native、Flutter、小程序同样成立。核心差别是：移动端的失败大多是**资源型**失败——内存、线程、电量、权限、网络抖动——单测照不出来。

## 1. 状态与刷新

- `@State` 只在组件内部用。跨层传递用 `@Prop`（单向）或 `@Link`（双向），嵌套对象改动要 `@Observed` + `@ObjectLink`，否则改了不刷新。
- 不在 `build()` 里做计算、排序、过滤、字符串拼接。这些放 `aboutToAppear` 或 `@Watch` 里，`build()` 只负责描述界面。
- 全局状态（AppStorage / 单例）只放真正跨页面的东西。页面内部状态别往上提。
- 页面返回时数据要不要刷新，先明确：`onPageShow` 刷新，还是靠状态同步。两套混用必然出现「改完看不出变化」。

## 2. 生命周期

| 时机 | 该做 |
|---|---|
| `aboutToAppear` | 读参数、拉首屏数据、注册监听 |
| `aboutToDisappear` | **反注册监听、清 Timer、断订阅、取消请求** |
| `onPageShow` / `onPageHide` | 页面级刷新、暂停动画与计时 |
| `onBackPress` | 有未保存内容时拦截并提示 |

漏掉 `aboutToDisappear` 的清理，是移动端最典型的隐性泄漏：页面退了，回调还在跑，下次进来收到两份数据。

## 3. 长列表与图片

- 超过一屏的列表用 `LazyForEach`，配 `IDataSource` 和稳定的 `keyGenerator`。用 `ForEach` 渲染上千条必然卡。
- key 用业务唯一 ID，不要用数组下标——删除中间项会让整列错位。
- 图片按显示尺寸取，不要拿原图塞进小 `Image`。列表项里避免每项都 `objectFit` 加载大图。
- 列表项内部避免重复创建对象和闭包，滚动时会放大成明显卡顿。

## 4. 页面跳转

- 路由参数要有类型，别用裸对象传。参数里不塞大对象，传 ID 让对方自己取。
- 避免重复 push 同一页面（连点两次进入两个实例）。跳转前判断或做防抖。
- 返回栈深度要有上限意识。深层页面用 `replace` 而不是 `push`。
- `Navigation` 与 `router` 两套方案不要在一个模块里混用。

## 5. 权限

- 用到时才申请，不在启动时一次性弹一堆。
- 申请前说明用途；被拒后必须有降级路径，不能白屏或死循环弹窗。
- 关键权限被永久拒绝时，引导去设置页，并保持应用可用。
- 权限清单最小化：`module.json5` 里不声明用不到的权限。

## 6. 网络与离线

- 每个请求都有超时、失败提示、重试入口。移动网络下「转圈到死」是最差体验。
- 页面退出时取消未完成请求，回调回来先判断页面是否还存在。
- 弱网/断网要有明确状态，不要拿空数据当成功。
- 有缓存的数据标清「上次更新时间」，别让用户以为是最新的。

## 7. 数据持久化

- 轻量配置用 Preferences，结构化数据用关系型存储（RDB）。不要用文件自己拼一套。
- 数据库要有版本号和迁移路径。升级丢数据是移动端最不可接受的事故。
- 敏感数据（令牌、密钥）用系统密钥库加密，不明文落盘，不写进日志。
- 写操作要考虑中途被杀：先写临时再原子替换，或接受事务回滚。

## 8. 界面适配

- 深浅色两套都要看，不要只测一套。
- 不同屏宽、折叠态、大字号下不截断关键信息。
- 安全区留白（刘海、手势条），按钮不能被系统手势吞掉。
- 加载态用骨架或占位，避免布局跳动。

## 9. 性能与线程

- 主线程不做重计算、大 JSON 解析、批量文件 IO。重活用 `taskpool` 或 `Worker`。
- 对象创建、正则、序列化在循环里要留意。
- 动画用系统能力，不用定时器手搓帧。
- 包体积关注：无用资源、重复图片、未压缩的字体。

## 10. 测试

- 纯逻辑（换算、校验、状态机、解析）抽成不依赖 UI 的函数，这部分必须有单测。
- UI 与交互用可观察判据代替：进入看到什么、点击后什么变化、异常输入怎么提示。
- 每次只回归受影响页面，控制手测成本；但**权限被拒、断网、空数据、超长文本**这四种情况每次都要过一遍。

## 11. 收工前照着挑

`build()` 里算东西、漏 `aboutToDisappear` 清理、长列表用 `ForEach`、key 用下标、大图直塞、重复 push、启动就弹权限、请求不取消、空数据当成功、数据库无版本号、令牌明文、只测浅色、只测一种屏宽、主线程干重活。
